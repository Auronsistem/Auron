FAMILIA Y SEGURIDAD

🛡️ Controles parentales

El apoderado verifica su correo con un código de 6 dígitos y después indica el correo de la cuenta AUREON que desea supervisar. No se pide ni se guarda la contraseña de Gmail. El apoderado debe tener una cuenta AUREON registrada.

La verificación del apoderado se conserva en este dispositivo para recuperar las cuentas vinculadas al volver a abrir AUREON. Puedes cerrar esa sesión aquí cuando termines.

Administrar cuentas vinculadas

Esto elimina los controles y el historial de tiempo de esta vinculación. No se podrá recuperar automáticamente.

Los cambios se guardan para la cuenta seleccionada, no para las demás cuentas.
